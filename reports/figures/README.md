# Exploratory figures

`eda_visualizations.png` is the original development-sample figure, preserved without regenerating it during cleanup. It contains package-age, version-count, package-size, and metadata-completeness plots.

Regenerate it with `python scripts/eda_visualization.py` after reviewing the cleaned development dataset. The script overwrites the PNG and opens a plot window; see [the workflow](../../docs/workflow.md) for noninteractive execution.

This is exploratory evidence about the development sample, not model evaluation or the final experimental dataset.
